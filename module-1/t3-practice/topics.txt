Команда для создания топика (в моем случае выполняются в отдельном контейнере kafka-init):

```bash
kafka-topics --bootstrap-server kafka:29092,kafka-broker-2:29093 \
          --create \
          --if-not-exists \
          --topic topic.events.v1 \
          --partitions 3 \
          --replication-factor 2
```


Там же в контейнере будет вывод по топику:

```bash
kafka-topics --describe --topic topic.events.v1 --bootstrap-server kafka:29092,kafka-broker-2:29093
``

Поглядеть логи `docker logs -f kafka-init`
