# Module-3: Администрирование в Kafka

Цели:
- оптимизация компонентов
- мониторинг кластера
- алертинг


Можно выделить 4 ключевых показателя для оптимизации:
- пропускная способность (throughput) - кол-во сообщений в единицу времени
- задержка (latency) - время доставки от продьюсера до консьюмера
- доступность (availability) - способность работать при сбоях
- надежность (durability) - гарантия, что сообщения будут доставлены

Улучшить все показатели сразу нельзя - это компромисс!
